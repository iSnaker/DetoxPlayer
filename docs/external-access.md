# Внешний доступ по HTTPS

Схема: интернет → роутер (80, 443) → Caddy в Docker → клиентский API. Админка
(`8080`) наружу не публикуется и в Caddy не маршрутизируется. Музыка по-прежнему
монтируется только для чтения. Имя: `detoxplayer.duckdns.org` (задаётся
`PUBLIC_HOST` в `.env`), IP в DuckDNS — постоянный белый IP.

## 1. Роутер

Пробросьте на IP этого компьютера в локальной сети (лучше закрепить его за
компьютером в DHCP) один TCP-порт:

| Внешний порт | Внутренний порт |
| --- | --- |
| 443 | 443 |

Сертификат Let's Encrypt выпускается через TLS-ALPN прямо на 443, порт 80 не
нужен. Порты 8080 и 8081 не пробрасывайте.

## 2. Windows Firewall

Docker Desktop обычно открывает опубликованные порты сам. Если соединение
извне не проходит, создайте правило (PowerShell от администратора):

```powershell
New-NetFirewallRule -DisplayName 'DetoxPlayer HTTPS' -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow -Profile Private,Public
```

## 3. Запуск

Скопируйте `PUBLIC_HOST` из `.env.example` в `.env`, затем:

```powershell
docker compose -f compose.yaml -f deploy/compose.public.yaml up -d --build
docker compose -f compose.yaml -f deploy/compose.public.yaml logs caddy
```

В журнале Caddy должно появиться сообщение о полученном сертификате. Данные
сертификата хранятся в томе `caddy-data`.

## 4. Проверка

Отключите телефон от Wi-Fi и откройте в мобильном браузере
`https://detoxplayer.duckdns.org/health` — ответ `{"status":"ok"}`. Затем в
приложении укажите этот адрес и ключ устройства. Проверьте каталог,
воспроизведение, перемотку и отзыв ключа. Маршруты `/admin/*` и любые другие
пути вне `/health` и `/api/v1/*` возвращают 404.

Если вы проверяете адрес с компьютера в той же сети, он может не открываться из-за
отсутствия hairpin NAT на роутере; используйте мобильную сеть.

## Безопасность

- Caddy — единственный доверенный proxy (`172.30.0.10`). API берёт реальный
  адрес и схему из `X-Forwarded-*` только от него, поэтому лимит попыток
  считается по адресам клиентов.
- Ключ устройства передаётся только по HTTPS. Release-сборка Android запрещает
  HTTP; разрешение есть только в debug-манифесте.
- Тестовые ключи отзывайте после проверки. Ключ даёт доступ ко всей библиотеке.
- Чтобы закрыть доступ, остановите стек без публичного файла:
  `docker compose -f compose.yaml -f deploy/compose.public.yaml down`, затем
  `docker compose up -d`.

## Если порт 443 закрыт провайдером

Выпуск сертификата завершится ошибкой в журнале Caddy. Проверьте порт
из внешней сети. Нестандартный внешний порт для самого API возможен, но
сертификат Let's Encrypt тогда придётся выпускать через DNS-challenge DuckDNS
с токеном (нужен образ Caddy с плагином DNS).
