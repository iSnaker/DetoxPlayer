## Найденная и исправленная проблема

Часть старых русских ID3-тегов была записана байтами CP1251 с обозначением
Latin-1: например, название отображалось как `Ïîëèýòèëåí`.
Добавлено консервативное восстановление текста при чтении: результат должен
подтверждаться именем файла или компонентом пути. Неоднозначные значения
сохраняются; это не универсальное исправление любых повреждённых тегов.

После пересборки выполнена полная переиндексация: 5 138 треков без ошибок,
все ID сохранились. Через HTTP API и браузер подтверждены исправленные
название «Полиэтилен», исполнитель «Animal ДжаZ» и альбом «Как Люди».
Регрессионный тест проверяет чтение реальных ID3-фреймов и неизменность
байтов тестового файла; корректные русские и латинские теги сохраняются.

Музыкальные файлы не переписывались. Сравнение списков всех 7 124 файлов
до и после проверки не обнаружило изменений путей, размеров или времени
записи. Полное хеширование 60 ГиБ не выполнялось.

## Границы исходной проверки

Отключение реального диска и удаление музыкальных файлов не выполнялись:
недоступность источников и ошибки обхода проверяются искусственными тестами.
На момент исходной проверки клиентская авторизация, выдача аудио, обложки,
Flutter и внешний HTTPS ещё не были реализованы.

## Клиентский API — следующий серверный этап, 29 октября 2026

Реализован и проверен отдельный сервис `api` на `127.0.0.1:8081`, админка
сохранена на `127.0.0.1:8080`. Оба контейнера healthy и монтируют музыку
с `RW=false`. Корневые файловые системы контейнеров также read-only.

- Клиентский каталог содержит все 5 138 треков. Контрольная сумма ID и
  относительных путей совпадает с исходной проверкой.
- HEAD реального MP3 возвращает его размер; диапазон байтов 1000–5095
  получен с HTTP 206 и побайтно подтверждён сравнением SHA-256 с оригиналом.
- Получена JPEG-обложка. Через HttpOnly web-сессию проверен suffix Range
  без заголовка Authorization, как потребуется браузерному audio element.
- Десять реальных HTTP-потоков отменены после первых байтов. После отмены
  открытых дескрипторов музыкальных файлов в API-контейнере не осталось.
- Отзыв временного ключа блокирует каталог, аудио и обложки и для Bearer,
  и для cookie. Временный ключ `Client API smoke test (revoked)` отозван.
- `/admin/state` на клиентском порту возвращает 404; время последнего
  использования ключа отражается в административном API и панели.
- Автоматические тесты покрывают границы Range, If-Range, HEAD, отмену,
  symlink/traversal, недоступность диска, удаление источника, истечение и
  ограничение количества сессий, CSRF, лимит попыток, гонку отзыва ключа,
  приоритет/обновление обложек и обновление их кэша после полного сброса.
- Повторное сравнение всех 7 124 исходных файлов: изменений пути, размера
  или времени записи нет. Полные аудиофайлы не копировались в репозиторий.
