# Detox Player: визуальное оформление

Обновлено 30 октября 2026.

## Направление

Спокойный музыкальный интерфейс с крупными заголовками, свободными отступами,
обложками и компактным мини-плеером. Светлая палитра взята из авокадо:

| Роль | Цвет |
| --- | --- |
| Основной фон | `#F6F8F0` |
| Мягкие зелёные поверхности | `#DEE9D6` |
| Основной текст | `#263C2C` |
| Жёлтый акцент кнопок | `#F1D88B` |
| Коричневый акцент | `#805037` |

Тёмная тема использует глубокие зелёные поверхности и тёплые светлые акценты.
Выбор темы следует настройке системы. Тема находится в `app/lib/design/`.

## Экраны

- Старт и подключение: авокадо, название **Detox Player**, поля сервера и ключа.
- Медиатека: крупные заголовки, мягкое поле поиска, обновлённые карточки и списки.
- Альбом: большая обложка и действия Play → Playlist → Shuffle → Download.
- Мини-плеер: компактная строка; по нажатию открывается полноэкранный плеер.
- Полный плеер: обложка, перемотка с буферизацией, предыдущий/следующий,
  shuffle/repeat, повтор после ошибки и открытие редактируемой очереди.

## Иконки и идентификатор

Исходное изображение пользователя сохранено в `app/assets/branding/avocado.png`.
Использована исходная квадратная композиция без перерисовки. Платформенные
размеры подготовлены `flutter_launcher_icons`: Android legacy/adaptive и
непрозрачные iOS AppIcon. Углы iOS-иконки обрезает сама система.

Android namespace/applicationId и MainActivity: `com.snapix.detoxplayer`.
Отображаемое имя Android/iOS: **Detox Player**. iOS bundle identifier не менялся.
Новый Android ID устанавливается отдельно от старого приложения: ключ,
плейлисты и скачанные файлы между этими установками автоматически не переносятся.

Настроены нативные стартовые фоны и логотипы Android/iOS. Android 12+ использует
системную заставку с иконкой; после инициализации Flutter показывается брендовый
экран восстановления подключения.

Для повторной генерации иконок из `app`: `dart run flutter_launcher_icons`.
У версии 0.14.4 обнаружено изменение постороннего параметра Xcode: после генерации
проверить, что `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS`
остаётся `YES`, а не `AppIcon`. В текущем проекте исправлено.

## Проверки

- `flutter analyze --no-pub`: без замечаний.
- `flutter test --no-pub`: 38 тестов, включая узкий экран, крупный текст,
  клавиатуру и переход из мини-плеера к управлению и очереди.
- Android debug APK собран с новым ID и иконками.
- Проверены размеры и отсутствие alpha у 25 iOS-иконок, корректность XML заставки.
  Нативная iOS-сборка и внешний вид на iPhone требуют проверки на Mac/Xcode.
- Превью реально отрисованных Flutter-виджетов: `app/build/design-preview/`.
  Музыка в превью — тестовые данные; обложки без сети показаны заглушками.

Для обновления PNG-превью:

```powershell
flutter test test/design_test.dart --dart-define=DETOX_CAPTURE=true --dart-define=DETOX_PREVIEW_FONTS=E:/Flutter/flutter/bin/cache/artifacts/material_fonts
```

Путь к шрифтам заменить на `bin/cache/artifacts/material_fonts` своего Flutter SDK.
Обычные тесты не требуют этого параметра и не записывают изображения.
